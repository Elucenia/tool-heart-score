# درجة HEART

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/heart-score)

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### القصة المرضية

`h`

- `0` — قليلة الاشتباه
- `1` — متوسّطة الاشتباه
- `2` — مرتفعة الاشتباه

### ECG

`e`

- `0` — طبيعي
- `1` — تغيّر غير نوعي في إعادة الاستقطاب
- `2` — انخفاض مهمّ في مقطع ST

### العمر

`a`

- `0` — ≤ ٤٥ سنة
- `1` — \> ٤٥ و \< ٦٥ سنة
- `2` — ≥ ٦٥ سنوات

### عوامل الخطر

`r`

- `0` — لا شيء
- `1` — ١ أو ٢
- `2` — ≥ ٣ أو مرض تصلّب شرايين معروف

### التروبونين

`t`

- `0` — ≤ الحدّ الطبيعي
- `1` — \> ١× و \< ٣× الحد الأعلى الطبيعي
- `2` — ≥ ٣× الحد الأعلى الطبيعي

## إصدار الطريقة

HEART/Backus 2013: ٥ مكونات بدرجات ٠–٢، والمجموع ٠–١٠؛ العمر ≤٤٥ أو \>٤٥ و \<٦٥ أو ≥٦٥ سنة؛ التروبونين ≤الحد الأعلى الطبيعي أو \>١×الحد الأعلى الطبيعي و \<٣×الحد الأعلى الطبيعي أو ≥٣×الحد الأعلى الطبيعي؛ وليس HEART Pathway بالتقييم المتسلسل

## المعادلة الموثقة

0 إلى 2 نقطة لكل بند: H القصة المرضية، E تخطيط القلب، A العمر، R عوامل الخطر، وT التروبونين. المجموع 0 إلى 10.

عوامل الخطر: ارتفاع الضغط واضطراب الدهون والسكّري والسمنة (BMI \> 30) والتدخين الحالي أو الحديث وسوابق عائلية لمرض تاجي مبكّر.

## الحدود والفئة السكانية

دُرست HEART الأصلية في قسم الطوارئ لدى أشخاص لديهم ألم صدري واشتباه بمتلازمة تاجية دون ارتفاع مقطع ST. لا تعني الدرجة المنخفضة خطرًا معدومًا، ولا يكافئ المجموع الأصلي HEART Pathway الذي يتضمن التقييم المتسلسل. يتطلب أمان الخروج وتوقيت قياسات التروبونين والاستبعادات البروتوكول المقابل.
